# Translated by Hisham 🌍

## مشروع من تطوير: Hichamdzz

تطبيقين Flutter متكاملين للترجمة الفورية:

### 📱 التطبيق الرئيسي (translated_by_hisham/)
تطبيق ترجمة احترافي بالمميزات التالية:
- 🎤 ترجمة صوت↔صوت فورية
- 🔍 كشف اللغة تلقائياً (صوت + نص)
- 🔴 وضع البث المباشر (تيك توك لايف)
- 🔵 زر عائم يعمل فوق كل التطبيقات (مثل Auto Clicker)
- ⚡ خدمة خلفية — يشتغل داخل أي تطبيق
- 🗣️ اختيار أصوات متعددة
- 🎬 ترجمة فيديو مع سبتايتل
- ✍️ ترجمة نصية
- 🔄 ترجمة بالاتجاهين
- 📦 يقبل تحديثات من تطبيق الأدمن
- 🎨 تصميم عصري 2026 — Glassmorphism + Gradients + Animations

### 🔧 تطبيق التحديثات (update_manager/)
لوحة تحكم المطور:
- 🔐 محمي بكلمة سر (Hichamdzz)
- 📊 لوحة معلومات — حالة التطبيق والإحصائيات
- ⚙️ إدارة الميزات — إضافة/تعطيل ميزات
- 🚀 دفع تحديثات للتطبيق الرئيسي
- 🔴 إيقاف/تشغيل التطبيق عن بعد
- 🎨 تصميم admin مظلم مع neon accents

## 🛠️ كيف تبني التطبيق

```bash
# التطبيق الرئيسي
cd translated_by_hisham
flutter pub get
flutter build apk --release

# تطبيق التحديثات
cd ../update_manager
flutter pub get
flutter build apk --release
```
